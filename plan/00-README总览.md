# pit-monitoring-checker · 总览

建筑基坑工程监测数据判读与预警工具（离线桌面 exe，规则优先，零 LLM、零网络，判定挂条款号）。

**它管的是一座基坑从开挖到封底的全部量测读数**：台账持久、阈值来源可溯、"报警未处置"能一路跟着下一个轮次。
大模型聊天框没有你的上一轮数据，也不会替你守住"超标未闭环不得进入下一工况"这条纪律。
