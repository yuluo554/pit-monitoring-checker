## 三、合成数据纪律与白名单

本项目的演示/评测数据全部为程序生成，**不得出现任何真实工程、真实单位、真实人员信息**。允许使用的假数据形式（白名单，新增需在此登记）：

| 类别 | 白名单形式 | 示例 |
|---|---|---|
| 工程名 | `示例`/`SYN` 前缀 + 虚构地名 | `SYN·临江路地块 3 号基坑` |
| 单位名 | 虚构且明显非实名 | `示例岩土监测有限公司`、`某建设集团第 9 项目部` |
| 手机号 | 199 保留号段 | `19900000000`～`19900009999` |
| 身份证/信用代码 | 格式合法但标注 `SYN`，校验位不追求真实 | `91SYN000000000000X` |
| 图纸/方案编号 | `SYN-JK-2026-0001` 式 | — |
| DOI / 文献 | 保留前缀 | `10.9999/SYN.0001` |
| 坐标 | 相对坐标或明显虚构点位；不用真实监测点位坐标 | — |
| 日期 | 允许使用近未来/虚构工期 | — |

异常事件植入约定（真值格式，M1 落地）：

```
event_id, point_id, round_index, event_type, injected_magnitude, expected_first_alarm_round
```

`event_type ∈ {step, rate_burst, drift, missing, outlier, unit_error, duplicate_report}`；每座虚拟基坑的真值文件与数据文件同目录、同名后缀 `.truth.csv`，导入器须校验两者行数一致。

## 四、目录约定

```
data/
  raw/            合成监测时序（不入库真实数据）
  truth/          异常事件真值
  golden/         评测期望结果与复现命令
  standards/      依据原文摘录（仅本地，不提交含版权全文的文件 → .gitignore 已排除）
```

`data/standards/` 只允许存放自己整理的条款摘录笔记，禁止提交标准全文扫描件 —— 已在 `.gitignore` 中排除。
